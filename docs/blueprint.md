# **App Name**: Juan Dev Studio Landing

## Core Features:

- Hero Section: Display an impactful title, descriptive subtext, and a prominent CTA for immediate user engagement.
- Social Proof Metrics: Showcase key metrics like load time, conversion increase, and tech stack to build trust and credibility.
- VIP Services Grid: Present a grid of service cards (stages) detailing the 7-14 day development process with gold-border-gradient styling.
- Pricing Plans: Compare 'Web Base' and 'Web Sales Engine Pro' plans, highlighting the benefits of each option to facilitate decision-making.
- FAQ Accordion: Address common objections regarding pricing and delivery times through an interactive FAQ accordion component.
- Guarantee Block: Display a distinct message ensuring high-quality deliverables to build confidence in service commitment.
- Data-Driven Content: Centralize all page content within a `/content` directory using a `juanDevStudioContent` object for easy updates and maintenance.

## Style Guidelines:

- Background color: Dark backdrop (#0a0b10) to establish a premium dark aesthetic.
- Primary color: Golden accent (#f2b90d) to draw attention to key elements and CTAs.
- Font: 'Manrope' sans-serif for a modern and readable user experience. Note: currently only Google Fonts are supported.
- Mobile-first responsive design ensuring optimal viewing experience across devices.
- Grid-based layout for services and pricing sections to provide structured information.
- Subtle glow effects on primary interactive elements to enhance visual appeal.
